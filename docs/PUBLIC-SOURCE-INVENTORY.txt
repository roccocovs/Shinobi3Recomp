The GitHub repository contains source and local-build tooling; the precompiled Windows executable is distributed separately as a GitHub Release asset. The source tree excludes the ROM, generated Shinobi C, compiled game executable, PDBs, saves, and private diagnostics. Review actual files as well as `.gitignore`.
